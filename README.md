# Aula 08 - Projeto MVC

## Descrição
Projeto back-end desenvolvido com Node.js e Express, utilizando o padrão MVC e arquivos JSON.

## Funcionalidades
- CRUD de clientes, pedidos, produtos e itens.
- Cálculo do subtotal dos itens.
- Relacionamentos conforme o diagrama UML.

## Tecnologias
- Node.js
- Express
- JavaScript
- JSON
- Thunder Client
